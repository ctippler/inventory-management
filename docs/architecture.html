Factory Inventory Management: Architecture

A two-tier demo app. A Vue 3 single-page app on port 3000 calls a FastAPI service on port 8001. That service serves mock data that it loads from JSON files into memory when it starts. There is no database, no authentication and no write path that persists anything.

System architecture

Tech stack

Frontend
  • Vue 3 (Composition API, setup())
  • vue-router 4 (HTML5 history)
  • axios for HTTP
  • Vite 8 dev server and build
  • Custom i18n: locales/en.js, ja.js
  • No UI or chart library; charts are hand-built SVG
Backend
  • Python ≥ 3.11, managed with uv
  • FastAPI with Pydantic v2 models
  • uvicorn ASGI server
  • CORS open to all origins
  • Auto docs at /docs
Data and tooling
  • JSON files, held in memory
  • pytest + FastAPI TestClient (40 tests in tests/backend)
  • scripts/start.sh / stop.sh
  • Claude Code setup: .claude/ agents, commands, hooks, skill; .mcp.json (Playwright, GitHub)

Data flow: changing a filter

  1. The user picks a value in FilterBar.vue, for example Warehouse = Tokyo. The value is written to a module-level ref in useFilters.js, so every view shares the same filter state.
  2. A view such as Dashboard.vue watches those refs. It calls getCurrentFilters(), which maps selectedLocation to warehouse and selectedPeriod to month.
  3. api.js adds only the non-"all" values as query params, for example GET /api/dashboard/summary?warehouse=Tokyo.
  4. FastAPI runs apply_filters() (warehouse, category, status) and then filter_by_month() over the in-memory lists. Quarters are expanded through QUARTER_MAP.
  5. The response is validated against its Pydantic model and returned as JSON.
  6. The view stores the result in refs. Computed properties derive KPIs, chart series and tables, and the template re-renders.

Observations

Client calls endpoints the server doesn't have

api.js defines /api/tasks and /api/purchase-orders, but main.py has no such routes. Both return 404 on the running server. Task and purchase-order features will fail.

Reports page diverges from the patterns

It hard-codes the API URL, skips api.js, and ignores useFilters. The workshop's bug bounty says it also has i18n and console-logging bugs.

Backlog view is orphaned

Backlog.vue exists but isn't registered in main.js, so no route reaches it. Backlog data still appears on the Dashboard.

Stateless by design

All data is read once at startup, and nothing writes back to it. Restarting the server resets everything, and the dashboard's backlog count ignores filters.
